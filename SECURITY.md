# Security

1.0.x is the current development line. No guaranteed support response time.

Do not post credentials, OAuth codes, tokens or personal notes in public
issues. Use GitHub private vulnerability reporting when enabled via Security.
Otherwise contact the maintainer through GitHub to arrange a private channel
before sending details.

Never commit OAuth JSON, board.json, token files, browser profiles or .env
files. Test with synthetic notes and your own authorized Google account.
